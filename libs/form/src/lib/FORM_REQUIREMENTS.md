# Form Requirements

## Requirements

- [ ] Use react hook form Controller
- [ ] Use react hook form rules for validation (required, min, max, etc.)
- [ ] can always pass a custom zod validation function
- [ ] All inputs need to be wrapped in a form
- [ ] cant add just spaces to the input - this should fail validation
- [ ] use hook form formProvider; no need to pass control to the component
- [ ] use zod for validation
